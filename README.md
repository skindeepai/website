# SkinDeep Research

A research lab exploring preference learning, direct model decisions, direct coordinates and adaptive computation. The site is static HTML/CSS/JavaScript. The historical 2018-2019 work remains accessible alongside current experiments.

## Explore

- `index.html`: lab overview and sidebar navigation.
- `research.html`: 29 registered questions, status and next steps.
- `results.html`: measured pilots, failures and limitations.
- `demo.html`: local preferences, seeded sessions and blind evaluation.
- `coordinate-lab.html`: local screenshot annotation; no browser model.
- `history.html` and `archive/2026-09/`: historical record and pre-lab pages.

## Run the site

No bundler or backend required:

```sh
python scripts/refresh_research.py
python scripts/build_site.py
python -m http.server 8768 --bind 127.0.0.1
```

Open `http://127.0.0.1:8768/index.html`. Edit `content/pages.json` and `content/demo.html`, then rebuild. Shared layout/navigation live in `scripts/build_site.py` and `lab.css`. Research/results bodies are generated by `refresh_research.py` from the protocol and measured artifacts; edit those sources instead.

Current pages use short explanations and compact, familiar illustrations in `content/pages.json`. Technical material remains available in expandable sections. Plain-language experiment questions live in `content/research-labels.json`; `refresh_research.py` keeps those labels alongside the full protocols and measured results.

## Validate and reproduce

```sh
python scripts/check_site.py
python -m pip install -r experiments/requirements.txt
python experiments/run_synthetic.py
```

Browser checks: `node scripts/test_browser.cjs`. Use Playwright/Chromium in a separate tooling environment, or set `PLAYWRIGHT_MODULE` to an existing playwright-core module. The script tests 28 pages at seven widths with a two-renderer cap. See [experiments/README.md](experiments/README.md) for model downloads and runtime limits.

Accessibility and enlarged-text checks: `node scripts/audit_accessibility.cjs` against the local preview. Set `AXE_CORE_PATH` to a separate axe-core installation. See the [accessibility review](docs/accessibility.md) for coverage, findings, and reproduction commands.

The first Qwen pilot demonstrates real layer skipping but **fails the proposed quality tolerance**. The coordinate pilot reproduces an existing pointer head; it does not establish equal-quality speedups over JSON. Human studies and data/hardware-dependent work remain open.
