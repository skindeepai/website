Working past the context limit

What long-context experiments taught us about files, memory and speed.

A small working context can handle a much longer job. The useful trick is to keep records in files, bring back what matters, and preserve the current state. Saving a file does not give the GPU unlimited working memory.

Three things we learned

1.9 minutes

A long task with a small context

With files allowed, the model answered all 24 questions about a 121K-token stream. Its active context stayed under 9K tokens.

How files helped
About 2 seconds

A faster start on repeat questions

A question over a cached 200K-token document started in about 2 seconds. A separate cold read took 114 seconds. Caching saves rereading.

What caching speeds up
Length still costs

Writing slows as context grows

Observed output speed was about 127 tokens/s near 8K context and 27 tokens/s near 250K. A cache does not remove that cost.
