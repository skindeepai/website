Use case · Idea to test

Suggest an image annotation

Mark a starting point for a human editor.

An annotation tool could suggest where an object starts, then let a person correct the point or outline. The useful result is editable geometry rather than a sentence describing the picture.

Where the small model fits

A vision representation feeds a point, box or mask head suited to the task. A single point is not a substitute for a complete object boundary.

What would need to work

Measure correction time and final annotation quality, including missing or repeated objects. Our coordinate workbench records manual labels; it does not infer object boundaries.
