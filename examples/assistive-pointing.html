Assistive pointing

Turn a requested control into a location.

Someone using voice or switch controls could ask for a visible button and confirm the highlighted target. The point output would be one part of an assistive interface.

Where the small model fits

A spatial head returns a location for the chosen control. The interface can preview the point and preserve a cancel path; speech input and action confirmation are separate components.

What would need to work

Measure successful tasks with intended users, including ambiguous and moving targets. There is no assistive-technology user study here; the screenshot demo only illustrates target location.
