Use case · Idea to test

Sort an inbox

Separate receipts, requests and newsletters.

An inbox tool could identify receipts, meeting requests and newsletters without drafting a response. An uncertain or unfamiliar message could remain in the main inbox.

Where the small model fits

A small classifier returns a folder label from an email representation. Easy messages could use an early exit or a smaller model; a larger model would handle the rest.

What would need to work

Evaluate on new senders and future mail, including the cost of hiding an important message. No email-routing or phishing-detection benchmark has been run here.
