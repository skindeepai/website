Cascade: test results

The recorded decisions, mistakes and processing time for the tiny-model fallback experiment.

Run a two-model fallback

This uses tiny BERT → larger BERT. It is a new pairing, not the measured tiny → Qwen cascade.

Dataset: ToxicChat0124 · 100 previously inspected messages: 50 toxic, 50 benign. A small exploratory test, not live moderation.

Which tiny model? Google’s BERT miniature with two layers and 4.37 million trained parameters. We fine-tuned it on 384 ToxicChat messages to return SAFE or BLOCK directly, without generating text. Uncertain messages go to a separate Qwen2.5-0.5B-Instruct classifier.

The cascade corrected three Qwen mistakes and introduced two new ones, including one toxic-message miss. Its higher total accuracy does not remove that trade-off.

Which model answered?

BERT tries every message first. If its score passes the confidence threshold, its answer is accepted. Otherwise Qwen makes the final decision.

The groups contain different messages. Comparing their accuracy rates does not tell us which model is better; the last column compares Qwen on exactly the same messages.

Every message ran BERT’s two layers. Only the 49 fallback messages ran Qwen’s 24 layers; 51 avoided Qwen entirely.

How this test was run

The tiny model trained on 384 messages; the older Qwen classifier trained on 1,400. Separate development examples selected the confidence thresholds. These 100 evaluation messages had already been inspected in earlier work.

Timing uses one warm CPU pass per method, rotating their order for each message. Input preparation and actual fallback work are included; loading is excluded. This is exploratory evidence, not validated moderation performance.
