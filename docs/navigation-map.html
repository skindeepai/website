        How to read this map

        Each left-hand page links into the selected page. Each right-hand page is a destination from it. Click a page to follow that connection; use browser Back to retrace your exploration. These are actual links, not a proposed hierarchy.

        Counts are distinct page pairs, including the declared navigation links for each demo mode. Mode-specific routes are labelled in the map and inventory. Repeated links, query modes and fragment targets stay visible in the full inventory. A link inside closed details is marked; it may take an extra interaction to reach. No incoming link does not mean a page is broken: it may still be reachable from the shared menu.

        Archive pages and raw evidence are boundary destinations; their internal links are not recursively mapped. Model downloads, buttons and generated report downloads are not page navigation.
