What runs?

These classifiers reproduce the routing, name-token and receipt baselines from their sealed training recipes. Exported numerical weights run in browser JavaScript; there is no LLM or remote prediction service. The editable examples are illustrations, not scored benchmark cases.

Model files load on first use. Receipt text is supplied by you; no OCR runs on this page. Names are highlighted, not removed, because missed names can remain. UNKNOWN means the router declined the request.
