The model looks for patterns in your ratings. It can then suggest something new, sort existing choices, or adjust a design toward your taste.

A suggestion is still a guess. You decide whether it is any good.

About the original project

SkinDeep first tried this with generated faces in 2018–19. The current browser demo uses simple drawings so you can see what changes. Real image generators and human preference studies need separate tests.
