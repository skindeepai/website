Choose what the task needs to remember

  1. For a long, changing conversation: keep searchable originals, short working notes and protected rules. Search finds things; notes keep the rules and the current state in view. Keeper and archive results · Retrieval alone.
  2. For a ledger or repeated calculation: let code maintain the totals. Files and code finished the 121K ledger in 1.9 minutes with all answers correct. For prose, the model can submit quoted changes for code to apply. See both workflows.
  3. When the source fits comfortably: try supplying it together. Whole-history reading led on the 56-question chat-memory test. Compare with archive and summaries.

Summaries can work: they matched the archive on the smaller retention test, but took longer. A summary alone cannot recover a detail it omitted. Accuracy and time, side by side.
